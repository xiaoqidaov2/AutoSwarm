# 📊 数据面板全栈开发\n\n## 项目结构\n\n```\ndashboard_project/\n├── README.md\n├── frontend/          # React前端应用\n│   └── package.json   # 前端依赖配置\n├── backend/           # Node.js后端API\n│   ├── package.json   # 后端依赖配置\n│   └── server.js      # 后端服务器代码\n└── database/          # 数据库相关\n    └── seed_data.sql  # 种子数据脚本\n```\n\n## 快速开始\n\n### 1. 后端启动\n```bash\ncd dashboard_project/backend\nnpm install\nnpm start\n```\n后端将在 http://localhost:3001 运行\n\n### 2. 数据库初始化\n访问 POST /api/dashboard/seed 接口初始化数据\n\n### 3. 前端启动\n```bash\ncd dashboard_project/frontend\nnpm install\nnpm start\n```\n\n## API接口\n| 方法 | 路径 | 说明 |\n|------|------|------|\n| GET | /api/dashboard/summary | 获取概览数据 |\n| GET | /api/dashboard/trends | 获取趋势数据 |\n| GET | /api/dashboard/categories | 获取分类数据 |\n| GET | /api/dashboard/details | 获取详细数据 |\n| POST | /api/dashboard/seed | 初始化种子数据 |\n| GET | /api/health | 健康检查 |\n\n## 角色分工\n- 🔴 领导者 - 项目规划与协调\n- 🔵 前端工程师 - React界面与数据可视化\n- 🟢 后端工程师 - API接口开发\n- 🟡 数据库工程师 - 数据模型与存储\n\n## 技术栈\n- **前端**: React + Ant Design + Recharts\n- **后端**: Node.js + Express\n- **数据库**: SQLite\n- **通信**: RESTful API
