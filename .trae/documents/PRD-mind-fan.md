# 心灵风扇 - 产品需求文档 (PRD)

## 1. 项目概述

### 项目名称
**心灵风扇** (Mind Fan)

### 项目类型
单页心灵慰藉互动网页应用

### 核心价值主张
一个带有旋转风扇动画的温馨心灵慰藉网页，为用户提供情感支持和放松体验。用户可以点击风扇感受旋转动画，并获取温暖的心灵鸡汤语句。

### 目标用户
- 需要情感支持和心灵慰藉的用户
- 喜欢温馨治愈系设计的用户
- 寻求片刻宁静和放松的用户

---

## 2. 用户故事与功能需求

### 用户故事
**作为一个访客，我希望**：在疲惫或情绪低落时，打开这个网页，通过视觉动画和温暖的话语获得心灵慰藉和放松。

### 核心功能

#### 2.1 旋转风扇动画 ⭐⭐⭐⭐⭐
- **描述**：页面中心有一个精美的风扇，持续旋转
- **交互**：用户点击风扇，风扇加速旋转并发出"呼呼"声效
- **视觉效果**：
  - 风扇有3-4片叶片
  - 采用渐变色彩（温暖的橙黄色调）
  - 带有柔和的光晕效果
  - 背景有微妙的粒子飘动效果

#### 2.2 心灵鸡汤展示 ⭐⭐⭐⭐
- **描述**：显示温暖、治愈系的励志语句
- **特性**：
  - 多个随机语句库
  - 定时自动切换（每15秒）
  - 点击风扇可立即切换新语句
  - 语句以优雅的方式淡入淡出

#### 2.3 舒缓背景 ⭐⭐⭐
- **描述**：营造温馨氛围的背景
- **元素**：
  - 温暖的渐变背景（米色到淡橙色）
  - 漂浮的柔和粒子
  - 柔焦效果
  - 渐变叠加层

#### 2.4 音效反馈 ⭐⭐⭐
- **描述**：提供沉浸式体验的音效
- **音效**：
  - 风扇旋转的呼呼声
  - 切换语句时的轻铃声
  - 可开关音效控制

#### 2.5 响应式设计 ⭐⭐⭐
- **描述**：适配各种设备
- **支持**：桌面端、平板、手机端
- **特性**：自适应布局，保持美观

## 3. 视觉与设计规范

### 3.1 设计理念
**温馨治愈系 + 现代极简**

整体感觉：像一个温暖的午后，阳光透过窗帘，微风轻拂。

### 3.2 色彩方案

#### 主色调
```css
--primary-warm: #FF9A56;      /* 温暖的橙黄色 */
--primary-soft: #FFD194;      /* 柔和的金色 */
--primary-pink: #FFCAD4;      /* 温柔的粉色 */
```

#### 背景色
```css
--bg-cream: #FFF8F0;          /* 奶油白 */
--bg-peach: #FFE5D9;          /* 桃子色 */
--bg-gradient-start: #FFF5EB;  /* 渐变起始 */
--bg-gradient-end: #FFE8CC;    /* 渐变结束 */
```

#### 文字色
```css
--text-primary: #5D4E37;      /* 深棕色（温暖但清晰） */
--text-secondary: #8B7355;    /* 次要文字 */
--text-quote: #C4956A;        /* 引言文字 */
```

#### 点缀色
```css
--accent-coral: #FF8A80;     /* 珊瑚红 */
--accent-sky: #81D4FA;       /* 天空蓝 */
--accent-mint: #A5D6A7;      /* 薄荷绿 */
```

### 3.3 排版规范

#### 字体选择
- **标题字体**：Noto Serif SC（优雅的衬线体，体现温暖感）
- **正文字体**：Noto Sans SC（清晰易读的无衬线体）
- **装饰字体**：Ma Shan Zheng（手写体，用于心灵鸡汤）

#### 字号规范
```css
--font-size-hero: 3rem;        /* 主标题 */
--font-size-quote: 1.5rem;    /* 心灵鸡汤 */
--font-size-body: 1rem;        /* 正文 */
--font-size-small: 0.875rem;   /* 小字 */
```

#### 行高规范
```css
--line-height-tight: 1.2;     /* 紧凑行高 */
--line-height-normal: 1.6;     /* 正常行高 */
--line-height-loose: 2;        /* 宽松行高 */
```

### 3.4 空间系统

#### 间距规范
```css
--space-xs: 0.25rem;   /* 4px */
--space-sm: 0.5rem;    /* 8px */
--space-md: 1rem;      /* 16px */
--space-lg: 2rem;      /* 32px */
--space-xl: 4rem;      /* 64px */
```

#### 布局节奏
- 页面使用垂直居中布局
- 风扇占据视觉中心
- 语句显示在风扇下方
- 保持大量留白，营造呼吸感

### 3.5 动效规范

#### 风扇动画
- **默认旋转**：360度 / 4秒，线性匀速
- **加速旋转**：360度 / 0.5秒，缓出效果
- **停止旋转**：4秒内逐渐减速至默认速度

#### 粒子动画
- **数量**：15-20个粒子
- **移动**：缓慢向上漂浮，随机水平漂移
- **透明度**：0.3 - 0.7，随机
- **大小**：5px - 15px，随机

#### 文字切换
- **淡入**：opacity 0→1, 600ms, ease-out
- **淡出**：opacity 1→0, 400ms, ease-in
- **切换间隔**：15秒

## 4. 组件清单

### 4.1 风扇组件 (Fan)
**视觉元素**：
- 圆形中心轴
- 3-4片弧形叶片
- 渐变色填充
- 外圈光晕效果
- 底部支架/底座

**状态**：
- 默认：缓慢旋转（4秒一圈）
- 激活：快速旋转（0.5秒一圈）
- 悬停：轻微放大（1.05倍）
- 点击：发出声音，光晕加强

### 4.2 心灵鸡汤组件 (QuoteCard)
**视觉元素**：
- 圆角矩形容器
- 半透明白色背景
- 引号装饰图标
- 手写风格文字
- 淡入淡出切换

**状态**：
- 显示中：opacity 1
- 切换中：opacity 0, transform translateY(-10px)

### 4.3 粒子系统 (ParticleSystem)
**元素**：
- 圆形粒子
- 不同大小（5px-15px）
- 不同透明度（0.3-0.7）
- 柔和色彩（粉、橙、金）

**行为**：
- 持续向上漂浮
- 随机水平漂移
- 到达顶部后从底部重新出现

### 4.4 音效控制器 (SoundToggle)
**位置**：右下角固定位置

**视觉**：
- 圆形按钮
- 音量图标
- 微妙的阴影

**状态**：
- 开启：图标为音量高
- 关闭：图标为静音
- 悬停：背景色加深

### 4.5 背景层 (Background)
**元素**：
- 渐变背景
- 模糊层
- 噪点纹理（可选）
- 粒子层

## 5. 技术实现规范

### 5.1 技术栈
- **前端**：纯HTML5 + CSS3 + JavaScript（无框架依赖）
- **动画**：CSS Animations + requestAnimationFrame
- **音频**：Web Audio API（带降级方案）
- **字体**：Google Fonts CDN

### 5.2 文件结构
```
mind-fan/
├── index.html      # 主页面
├── styles.css     # 样式表
├── app.js         # 应用逻辑
└── assets/        # 资源文件夹（可选）
```

### 5.3 性能优化
- 使用CSS transform进行动画（GPU加速）
- 粒子数量控制在20个以内
- 图片使用CSS绘制（无外部图片依赖）
- 音频延迟加载

### 5.4 浏览器兼容
- Chrome 80+
- Firefox 75+
- Safari 13+
- Edge 80+
