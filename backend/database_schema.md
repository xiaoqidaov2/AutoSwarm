# 数据面板 - 数据库设计文档\n\n## 数据库选择\n使用 SQLite 数据库，轻量级、零配置，适合数据面板应用\n\n## 数据表设计\n\n### 1. daily_metrics - 每日指标表\n| 字段名 | 类型 | 说明 |\n|--------|------|------|\n| id | INTEGER PRIMARY KEY | 自增主键 |\n| date | DATE NOT NULL UNIQUE | 日期 |\n| revenue | REAL | 收入 |\n| users | INTEGER | 用户数 |\n| conversion_rate | REAL | 转化率 |\n| page_views | INTEGER | 页面浏览量 |\n| created_at | TIMESTAMP | 创建时间 |\n| updated_at | TIMESTAMP | 更新时间 |\n\n### 2. categories - 分类表（可选扩展）\n| 字段名 | 类型 | 说明 |\n|--------|------|------|\n| id | INTEGER PRIMARY KEY | 自增主键 |\n| name | VARCHAR(100) | 分类名称 |\n| description | TEXT | 分类描述 |\n\n### 3. category_metrics - 分类指标表（可选扩展）\n| 字段名 | 类型 | 说明 |\n|--------|------|------|\n| id | INTEGER PRIMARY KEY | 自增主键 |\n| category_id | INTEGER FK | 关联分类ID |\n| date | DATE | 日期 |\n| metric_name | VARCHAR(50) | 指标名称 |\n| metric_value | REAL | 指标值 |\n\n## 初始数据\n- 生成365天的模拟数据（2024年1月1日 - 2024年12月31日）\n- 数据字段与后端API返回格式一致\n- 使用随机生成，保证数据多样性\n\n## 数据库文件位置\n- backend/data/dashboard.db\n
