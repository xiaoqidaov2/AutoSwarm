# 数据面板全栈开发\n\n## 项目概述\n\n这是一个全栈数据面板应用，用于可视化展示关键数据指标。\n\n## 技术栈\n\n- **前端**: HTML/CSS/JavaScript + Chart.js\n- **后端**: Python Flask REST API\n- **数据**: JSON模拟数据\n\n## 项目结构\n\n```\ndata_dashboard/\n├── README.md\n├── frontend/       # 前端代码\n│   ├── index.html\n│   ├── style.css\n│   └── app.js\n├── backend/        # 后端代码\n│   ├── app.py\n│   └── requirements.txt\n└── data/           # 数据文件\n    └── sample_data.json\n```\n\n## 开发计划\n\n1. 确定API接口规范\n2. 后端开发 - 数据API\n3. 前端开发 - 数据面板界面\n4. 前后端联调\n5. 测试与优化\n
